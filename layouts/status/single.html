This page reports whether the homelab fleet is up. It is a static page hosted on GitHub Pages, and the status it shows comes from Healthchecks.io, not from the homelab itself — so if the entire fleet loses power, this page still loads and still shows the fleet as down, instead of going blank along with everything else. Each host pings its own Healthchecks.io check once a minute (a "dead man's switch"); if the pings stop, the check — and this page — flips to down.
